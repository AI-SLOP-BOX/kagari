# Kagari UI Kit

eguiを継続し、通常の操作部品は `ui::kui` を入口とする。
Painterはタイムライン、ノード、カーブ、メーター、スコープ、ビューアーの特殊描画に使用する。

## 共通部品

- `button`: 通常・アクセント・補助操作。背景をeguiのVisualsで設定し、文字の上に背景を描かない。
- `tool_button`: 選択を保持する操作ボタン。長いラベルは省略して全文のツールチップを付ける。
- `section`: 折り返し可能な見出し。
- `PropertyGrid`: 実際のフォントでラベル幅を計測し、入力列を揃える。幅不足なら縦配置。
- `number` / `slider`: 数値・単位を同じ操作領域に表示。狭いスライダーは数値入力に切り替える。
- `drag`: 整数・小数の数値入力。単位、範囲、速度を指定し、操作はeguiのDragValueに委譲する。
- `vector` / `vector_axes`: 成分ごとの入力。幅不足なら縦配置し、位置と回転の軸名を指定できる。
- `panel` / `property`: 既存テーマのパネルと共通幅のプロパティ行。
- `combo`: 選択値を省略し、ホバーで全文を表示。
- `toggle`: eguiの入力処理を利用する切替操作。
- `text_field` / `color`: 名前とカラー編集の共通入口。
- `icon_label_button_at`: 既存のRectベース画面を移行するための互換入口。アイコンと文字の配置はeguiに任せる。新規画面では通常レイアウトを優先する。

ラベル集合は翻訳後の文言を渡す。言語や状態の決定をUIキットに持ち込まない。
スコープ内のスタイル変更だけを使い、他のパネルのスタイルを変更しない。
既存の `custom_widgets::ae_button` 系は互換入口としてUIキットへ委譲する。

## 移行状況

- 共通テキストボタン、アクセントボタン、文字アイコンボタン: 委譲済み。
- Align: 見出し、操作ボタン、折り返し、基準選択を移行。プロジェクト複製は操作時だけ。
- Audio: 見出し、音量・パンの入力列、波形切替を移行。
- Camera/Light: 画角、焦点距離、絞り、DoF、虹彩、最大ボケとキーフレーム操作、ライト名・種類・コーン・強度・色・影を移行。
- Home: 主操作ボタンの固定オフセット描画を共通アイコン付きボタンへ移行。
- DoF HUD: 共通フォームへ移行。ただし現在呼び出し元がなく、実画面での確認対象はCamera設定。
- Comp Settings: 名前、解像度、FPS、長さ、背景色などを共通フォームへ移行。プリセット表示を実際の値から決定。
- Character: 基本書式の入力列を共通化。可変フォントとText Animatorは未移行。
- CC Libraries: 検索、色、書式、素材行を共通化。素材行は可視行のみ生成。
- Camera Inspector: 位置・回転の入力を共通ベクトル部品へ移行。
- ノード表示: 画面外のノード・グリッド・接続線の描画を抑制し、長い名前を省略。ホバー背景をテーマに統一。

## ソース調査から残る設計課題

通常フォームはeguiのレイアウトと操作処理、特殊表示はPainter、画面全体はパネル配置の3層とする。
以下は関連部分の調査結果であり、GUI全ソースを全文読了したという意味ではない。

- ワークスペースの判定がツール状態、タブ番号、Contextの一時データに分散している。画面の責務を共通の状態へ整理する必要がある。
- workspace_managerはパネル幅・タイムライン高さを保存する。自由なドッキングの実装は確認できていない。
- Timelineは標準リサイズを無効にし、独自のドラッグ境界でPanelStateを書き換える構成。共通のリサイズ処理に整理する余地がある。
- Inspectorのキーフレームと式の更新処理は再利用する。外観変更のために編集ロジックを複製しない。
- Comp SettingsのWorking Color Spaceは一時的な選択状態で、実際のプロジェクト設定との接続は未解決。
- Characterの一部操作とレンズ設定などには標準部品が残る。共通化の完了とは扱わない。
- 右パネル選択は`RightPanel` enumへ移行済み。保存ワークスペースのJSONは従来の数値を維持し、読み書き時にenumへ変換する。
- Expressionの構文チェック結果は対象プロパティごとに保持し、入力文字列が変わった時だけ再compileする。
- 2つのFlowchartは共通の`FlowGraphModel`で親子・マット関係とノード位置を解決する。実行順はCompilerから取得するFlowchartだけで計算し、構造ビューではCompiler実行を省く。
- Inspector左ドックに残っていた旧Layer Properties実装は、タブ分岐がすべて先にreturnするため到達不能だった。Trackerイベント受信とProject/Effects表示を残し、到達不能な旧表示を削除。
- Graph Editorに型付き`GraphProperty`を追加。keyframe参照・Rove・interpolation更新・Puppet Pin/Effectの識別で利用し、既存の安定キー文字列はUI選択との互換境界に残す。残りの描画・編集分岐の型移行とファイル分割は継続課題。

## 継続する作業

1. Audioの残りの行を共通化する。Camera/Lightの表示中に作るUndo用のプロジェクト複製も見直す。
2. Inspector、ダイアログ、メニュー、タブへ順次展開する。
3. Assets/Effectsのヘッダーや通常フォームをeguiレイアウトへ移し、絶対座標を減らす。
4. UI共通のサイズ・余白・角丸のトークンを整理する。
5. 既存文言の一元管理とOS連動ローカライズを全画面へ適用する。
6. 実アプリで各画面、縮小幅、UIスケール、日英、無効状態、ドラッグ、Undoを確認する。

UI部品のテストだけでは視覚品質の完了判定にしない。
