# Kagari GUI Design Assets (Pixel-Perfect Ground Truth)

本ディレクトリには、Kagari（VFX・コンポジット・モーショングラフィックス制作スタジオ）の洗練されたモダンUIアセットが格納されています。

## ファイル構成
1. **ホーム画面**
   - `home.svg`: 最上部グローバルメニューバー（`ファイル(F)`、`編集(E)`、`表示(V)`、`ヘルプ(H)`）および中央ヒーローセクション（`+ 新規プロジェクト`、`📁 プロジェクトを開く...`、`素材からコンポジションを作成...`）を統合した完成版ホーム画面。
   - `home_hero.svg`: ヒーローアクション領域のスタンドアロンSVG。

2. **環境設定（Preferences Modal）全7タブ**
   - `preferences_general.svg`: 一般タブ（起動と終了、プロジェクト保存先など）
   - `preferences_performance.svg`: パフォーマンスタブ（メモリ70%スライダー、GPUレンダラー、キャッシュ管理）
   - `preferences_media.svg`: メディアタブ（静止画のデフォルト長、デコード、キャッシュ管理）
   - `preferences_display.svg`: 表示タブ（UIスケール、8色アクセントカラースウォッチ、グリッド間隔）
   - `preferences_playback.svg`: 再生タブ（再生品質、プリロール/ポストロール秒数スピンボックス、音量100%スライダー）
   - `preferences_shortcuts.svg`: ショートカットタブ（プリセット管理、2ペイン階層ツリー、キーバインドテーブル、編集/削除/新規アクション）
   - `preferences_filepath.svg`: ファイルパスタブ（プロジェクト、キャッシュ・一時ファイル、自動保存バックアップ世代数、アセットライブラリ）
